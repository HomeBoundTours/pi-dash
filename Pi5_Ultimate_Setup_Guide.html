Perplexica — Your Private Perplexity

Perplexica is a self-hosted Perplexity AI clone. It searches the web via your SearXNG instance, pulls relevant results, and uses your Ollama model to synthesize a cited answer. Research-quality answers, fully private.

Deploy Perplexica
git clone https://github.com/ItzCrazyKns/Perplexica
cd Perplexica
cp sample.config.toml config.toml
# Edit config.toml:
# OLLAMA_API_URL = "http://host.docker.internal:11434"
docker compose up -d

SearXNG — Private Search Engine

Self-hosted metasearch engine. Searches Google, Bing, DuckDuckGo simultaneously without tracking you. Feeds into Open WebUI and Perplexica.

Deploy SearXNG
services:
  searxng:
    image: searxng/searxng:latest
    ports: ["4000:8080"]
    volumes: [./searxng:/etc/searxng]
    restart: unless-stopped
🗣️
Goal: wake word → you speak → Pi thinks locally → speaks back. No internet. No Alexa. No Google. Faster response than cloud assistants once warmed up. Works during internet outages.

The Stack

👂
openWakeWord
Listens for your wake word ("Hey Pi", "Computer", anything you choose). Tiny, fast, runs in the background permanently.
🎤
Wyoming Whisper
OpenAI's Whisper model running locally. Transcribes your speech to text with near-perfect accuracy. Processes in ~1–2 seconds.
🧠
Ollama (Gemma 2B or Llama 3.2 3B)
Processes your question and generates a response. Use a fast 3B model for voice for near-instant replies.
🔊
Wyoming Piper
Text-to-speech. Converts the AI response to natural-sounding speech. Multiple voice options. Runs locally in milliseconds.
🏡
Home Assistant Integration
Voice commands control your home: "Turn off the bedroom lights", "What's the temperature", "Lock the front door".

Docker Compose

~/docker/voice/docker-compose.yml
services:
  wyoming-whisper:
    image: rhasspy/wyoming-whisper
    ports: ["10300:10300"]
    command: --model small-int8 --language en
    volumes: [./whisper-data:/data]
    restart: unless-stopped

  wyoming-piper:
    image: rhasspy/wyoming-piper
    ports: ["10200:10200"]
    command: --voice en_US-amy-medium
    volumes: [./piper-data:/data]
    restart: unless-stopped

  wyoming-openwakeword:
    image: rhasspy/wyoming-openwakeword
    ports: ["10400:10400"]
    command: --preload-model ok_nabu
    restart: unless-stopped
ℹ️
After deploying: Go to Home Assistant → Settings → Voice Assistants → Add assistant. Select Whisper (speech-to-text) and Piper (text-to-speech). Choose your preferred Ollama model as the conversation agent. Then add a wake word via openWakeWord. Done.

One-Time Phone Setup

1

Install Tailscale on phone

App Store / Google Play → Tailscale → sign in with the same account you used on Pi. Your phone now has a direct private connection to Pi from anywhere.

2

Install Open WebUI as a phone app

Open Safari/Chrome → navigate to http://[pi-tailscale-ip]:3000 → Share → Add to Home Screen. Full AI chat app, runs on your Pi.

3

Install Home Assistant app

Install from App Store → enter your Pi's local IP. Enable "Assist" (microphone button) for voice control from your phone.

4

Set up Immich auto-backup

Install Immich app → server URL = Pi's Tailscale IP → enable background backup. Every photo you take is now backed up to your Pi automatically.

1

Install Ollama

Native install — best Pi 5 performance
curl -fsSL https://ollama.com/install.sh | sh
# Start pulling models:
ollama pull llama3.2:3b    # Your daily driver (fast)
ollama pull llava:7b       # Vision — image analysis
ollama pull gemma2:2b      # Voice assistant (blazing fast)
2

Deploy Open WebUI

Full-featured AI chat interface
docker run -d -p 3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  --name open-webui --restart always \
  ghcr.io/open-webui/open-webui:main
3

Deploy SearXNG (Web Search for AI)

Private search engine → feeds Open WebUI
services:
  searxng:
    image: searxng/searxng:latest
    container_name: searxng
    ports: ["4000:8080"]
    volumes: [./searxng:/etc/searxng:rw]
    environment:
      - SEARXNG_BASE_URL=http://piserver.local:4000
    restart: unless-stopped

Then in Open WebUI → Settings → Web Search → enable, set to SearXNG at http://piserver.local:4000. Your AI can now search the web.

Self-hosted Perplexity AI clone
git clone https://github.com/ItzCrazyKns/Perplexica
cd Perplexica && cp sample.config.toml config.toml
# In config.toml set OLLAMA_API_URL = "http://host.docker.internal:11434"
docker compose up -d

Deploy Voice Stack (Wyoming)

Offline voice assistant

Full access to your home server from wherever you are.

Phone hits your WiFi. House comes alive.

  • Lights turn on at 70%. Thermostat returns to comfort temp.
  • Cameras disarm. A "Welcome home" notification hits your phone.
  • Immich finished processing today's photos — auto-backed up from phone

One tap. The whole room transforms.

  • Tap "Movie Night" scene in Home Assistant app
  • Lights dim to 10%. TV turns on. Jellyfin opens automatically.
  • No Netflix subscription. Your media library, your server.
  • Stream to any TV in the house simultaneously
🌙 10:30 PM — Bedtime

One button. House goes to sleep.

  • "Goodnight" scene: all lights off, doors locked (if smart locks), thermostat drops to sleep temp
  • Vaultwarden synced all password changes from the day
  • Nextcloud backed up your important files automatically
  • Pi idles at ~5W. Costs about $4/month in electricity.

automation:
  - alias: "Away Mode — Phone Left Network"
    trigger:
      - platform: device
        device_id: YOUR_PHONE_DEVICE_ID
        type: not_home
    action:
      - service: light.turn_off
        target:
          entity_id: light.all_lights
      - service: climate.set_temperature
        data:
          temperature: 68   # Set back temp
      - service: alarm_control_panel.arm_away
        entity_id: alarm_control_panel.home
      - service: notify.mobile_app_iphone
        data:

Example Automation — AI Morning Briefing

Pi cron → generates AI briefing and speaks it aloud
#!/bin/bash
# /home/aaron/scripts/morning-briefing.sh
# Cron: 0 7 * * 1-5  (weekdays at 7am)

WEATHER=$(curl -s "wttr.in/YourCity?format=3")
DATE=$(date "+%A, %B %d")

PROMPT="Give a friendly 3-sentence morning briefing for $DATE. Weather: $WEATHER. Keep it positive and under 30 seconds to speak."

RESPONSE=$(curl -s http://localhost:11434/api/generate \
  -d "{\"model\":\"llama3.2:3b\",\"prompt\":\"$PROMPT\",\"stream\":false}" \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['response'])")

# Speak via Piper TTS → speaker
echo "$RESPONSE" | piper --model en_US-amy-medium --output-raw \
  | aplay -r 22050 -f S16_LE -t raw -

ROM Naming Convention

EmulationStation and Skraper need ROMs named in the No-Intro or Redump standard to correctly identify games.

Correct naming examples
# Good — matches No-Intro standard:
Super Mario 64 (USA).z64
The Legend of Zelda - Ocarina of Time (USA).z64
Mario Kart - Double Dash!! (USA).iso

# File extensions by console:
# N64:        .z64 or .n64
# GameCube:   .iso or .rvz (compressed)
# SNES:       .sfc or .smc
# PS1:        .cue + .bin, or .chd (compressed)
# PSP:        .iso or .cso (compressed)

Add Pi to Moonlight

In Moonlight → Add PC → enter Pi's Tailscale IP. A PIN appears — enter it in Sunshine's web UI on the Pi. Paired.

4

Pick a game and play

Select any game in Moonlight. It streams the Pi's display to your phone. Pair a Bluetooth controller to your phone for full controls.

💡
Latency: On your home WiFi, streaming lag is nearly imperceptible (5–15ms). Over 5G from outside your house, N64/SNES/GBA games are perfectly playable. GameCube is borderline depending on your connection speed.
